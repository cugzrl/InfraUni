# 统一 DeTra 解码实验

数据是 nuScenes mini，训练 323 帧、验证 81 帧。初始化都是 `experiments/transfusion_voxel_LC_mini/epoch_1.pth`。优化器 AdamW，权重衰减 0.01，DeTra 学习率从 1e-4 收到 1e-6，检测器冻结。协议是 `docs/eval_protocol.md` 的 V3。下面的统一模型都是 2 个 epoch，和独立预测头、串联模型的 2 epoch 预算一致。D1 的 15 epoch 不放进这张表。

## 匹配

`class_gate` 用 TransFusion 候选类别加二维中心，距离超过 2 m 不分配。初始类别错了的 Query 拿不到这个真值。

`cost` 只分配一次，并让两个 Refinement block 共用。代价是候选中心的 L1、对数尺寸、圆周朝向、DeTra 第 0 个 block 的类别对数概率和存在概率。没有 TransFusion 类别硬门。匈牙利算法保证一个真值只分给一个 Query，中心距离超过 2 m 的配对再丢掉。旧的 `match_queries` 留着，日志里的 `switch` 是两种分配不一致的 Query 比例。

## 检测输出

发布结果来自 DeTra，不来自 TransFusion：

- 框是激光坐标系的 x、y、z、w、l、h、yaw，再接二维速度
- 类别是 `class_logits` 的 argmax
- 分数是存在概率乘最大类别概率
- 轨迹起点是当前中心加上预测偏移；预测损失使用断开梯度的当前中心

评估只做范围过滤，不做 NMS。这和 LC 配置里的 `nms_type=None` 一致。预测指标再丢掉分数低于 0.1 的 Query。

| `u_cost` 代价匹配 | 0.530 | 0.508 | 0.465 | 0.427 | -1.314 | 1.033 | 1.720 | 0.261 | 0.243 → 0.244 m |

B 和 C1 来自 `docs/archive/DETRA_JOINT_V3.md` 的 V3 协议。`u_cost` 训练 1134 秒。它的尺寸对数变化是 0.041，`u0` 是 0.248；未匹配预测从 8142 降到 5053。中心仍然几乎不动，最终 mAP 仍低于冻结候选的 0.530。代价匹配减轻了错误尺寸和重复框，还没有让 DeTra 修正定位。

`u0` 的框平均只移动 0.037 m，尺寸对数变化 0.248，朝向变化 0.064 rad。匹配上的中心误差没有下降。DeTra 这一阶段没有修正定位，尺寸和分数变化把 mAP 从 0.530 拉到 0.456。

EPA 为负的主要来源是重复 Query。`u0` 在行人上有 5834 个未匹配预测，汽车 EPA 仍是 0.029，minADE 0.620。检测 AP 用完整 PR 曲线，所以行人 AP 仍有 0.91；预测 EPA 把 0.1 分以上的 Query 都算进去，没有 NMS。

## 监督

每个 Refinement block 都有分类、存在性、中心、尺寸、朝向、速度和轨迹损失，再对 block 数取平均。`u_causal` 第 1 步的梯度范数：

| 模块 | 检测 | 预测 |
| --- | ---: | ---: |
| `class_head` | 5.312 | 0 |
| `object_head` | 1.174 | 0 |
| `box_head` | 0.482 | 0 |
| `future_head` | 0 | 0.515 |
| `time_attn` | 5.750 | 1.005 |
| `query_proj` | 6.358 | 0.409 |

预测损失更新共享 Query 和时间注意力，不更新框头。检测损失不更新未来轨迹头。可训练参数 2228321。checkpoint 含优化器、步数和随机数状态。非有限梯度会恢复参数并停止，不写坏权重。

简化的多尺度 BEV 仍是 512 通道插值到 DeTra 的单尺度图。这一轮没有改成 FPN。`u0` 和 `u_nofore` 的中心误差相同，说明预测损失不是中心不动的原因；零初始化的框头在 2 个 epoch 后也只移动了几厘米。
