# 跨帧 Query 记忆

ForeSight 的官方代码还没有公开。下面的机制按论文实现，范围限制在现有 TransFusion-LC 和 MC-DeTra 上。

## 论文里真正起作用的部分

ForeSight 维护一份共享记忆 `q_mem`，形状是物体数、历史长度、未来模式数和通道数。每个新时刻先用自车位姿把上一时刻的位置变到当前坐标系，再按队列丢掉最旧的一项。检测 Query 由当前 anchor 初始化，并和上一帧留下的时序 Query 一起做自注意力，再去看完整历史和图像 token。预测 Query 用检测 anchor、轨迹 anchor，以及上一帧最好的未来假设作为额外模式。预测分支看自己的未来、历史预测，然后再看检测 Query。

损失是检测、预测和辅助项的加权和。预测目标只分配给 2 m 以内的检测。论文的增益来自“过去作出的未来假设，对齐到当前帧之后，变成当前检测和下一轮预测的运动先验”。它不是用预测损失去拉当前框的中心。

论文在完整 nuScenes 上相对 StreamPETR 提高约 2.1 个点 mAP，相对 UniAD 提高约 9.3 个点 EPA。那是视觉多视角检测器，带地图编码和较长记忆。InfraUni 的检测器是 LiDAR-Camera TransFusion，记忆先做成短窗口，用来检验这个先验是否有用。

## 已经有的和还没有的

已经有的是同一帧里的检测 Query 注入 DeTra、6 个运动模式、类别内一次匹配、可选的因果时间 mask，以及 D1 那种断开的轨迹原点。C3 只在反传后恢复检测参数的梯度，前向里未来 Query 仍能看到当前 Query。

还没有的是跨帧共享记忆、把历史预测变到当前坐标系后再送进检测、用过去的轨迹假设初始化新的预测 Query，以及按可靠性决定这条历史能不能参与检测。推理不能读取未来真值。

## 这次实现的最小闭环

`infrauni/joint/memory.py` 里有两个部件。

`QueryBank` 保存最近 3 帧、每帧分数最高的 32 个 Query。内容是断开梯度之后的特征、框中心、分数、类别和多模式轨迹。`scene` 变化时清空。召回时丢掉时间戳大于等于当前帧的记录，所以记忆里只有当前时刻之前的观测和预测。

位置对齐用 `lidar_to_global = ego2global @ lidar2ego`。过去点到当前雷达坐标是 `inv(T_now) @ T_past`。nuScenes mini 的车在动，所以即使路侧传感器静止，这条变换也要保留。路侧静止时它退化为恒等或标定差。mini 的 info 没有 `scene_token`，场景 id 从 `v1.0-mini/sample.json` 补上。

检测模式使用对齐后的历史框中心。预测模式使用轨迹第 0 个模式在 `round(age / 0.5)` 处的点，再变到当前雷达坐标。0.5 s 是 nuScenes 关键帧的名义间隔。

`MotionPrior` 是一层残差注意力。当前检测 Query 和记忆 token 都加上二维位置。输出线性层初始化为 0，所以训练开始时检测框与关闭记忆时相同。单元测试里残差输出和输入的最大差为 0。Query 的位置取自 LiDAR decoder 输入的 heatmap 提案，再用 TransFusion bbox coder 的 `voxel_size`、`out_size_factor` 和 `pc_range` 换成米。这是提案位置，不是把历史预测直接写成新的检测中心。

可靠性是检测分数、模式离散度、时间衰减和跨帧观测误差的乘积。观测误差是这条历史预测与记忆里更晚、但仍早于当前帧的检测之间的最近距离，权重为 `exp(-error / 2)`。`reliable` 关闭时权重为 1。四项都限制在 0 到 1。

`tools/train_joint.py` 增加了四个开关，检测器保持冻结，框模式为 `none`，轨迹原点断开：

| 变体 | 记忆 |
| --- | --- |
| `s_det` | 只召回历史检测 |
| `s_forecast` | 只召回历史预测 |
| `s_both` | 两者都召回 |
| `s_reliable` | 两者都召回，并乘可靠性 |

`--ordered` 按 info 顺序走帧，不再每个 epoch 打乱。记忆实验必须用它。B、D1、F0 不打开这些变体。

官方检测损失在记忆打开时仍然计算。检测器参数冻结，梯度通过检测头的输入回到先验。送给 DeTra 的 Query 是先验输出的断开副本，预测损失不训练这条残差。这样保留了“预测去帮助检测”的方向，同时避免再用预测损失拉动当前中心。

两步冒烟（`s_both`，有序）已经跑通：可训练参数 2360417，当前框与轨迹 t=0 对齐，第一步 `loss_det` 1.660、`loss_forecast` 3.227，`box_head` 梯度为 0。第一步记忆为空，先验还没有输入。这个结果只说明形状和反传没有立刻坏掉，不能说明 mAP 上升。

## 还不能下的结论

五个消融还没有在 mini 上按同一初始化、同一数据和同一协议训练。历史预测有没有提高当前 mAP 和 NDS，尤其是低分、短遮挡和运动变化明显的目标，要等这组对照做完再写。若 mAP 没有提高，先查提案位置是否太粗、第 0 模式是否代表了多模式假设、以及 3 帧窗口里有多少 token 真的落在目标附近。在这之前不加长记忆，也不再堆注意力层。
